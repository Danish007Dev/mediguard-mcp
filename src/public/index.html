Safety Intelligence Tools

MediGuard bundles five specialized clinical logic tools, exposed via standard Model Context Protocol endpoints.

🧪

Drug-Drug Interactions

Normalizes drug names using the NIH RxNorm API and cross-references them against OpenFDA drug labels to detect interactions.

👴

Beers Criteria (Geriatric)

Flags high-risk medication categories (e.g. benzodiazepines, sedatives) in patients aged 65 and older based on AGST guidelines.

🚫

Contraindications

Verifies active ingredients against patient-specific clinical conditions, lab parameters (e.g. eGFR), and allergies.

📊

Safety Scoring

Generates a weighted 0-100 safety score, complete with detailed deduction breakdowns and therapeutic duplication flags.

🔄

What-If Simulation

Simulates adding, removing, or replacing medications in a patient's profile and returns the exact score delta.

🛡️

SHARP Compliance

Strict HIPAA-ready design. Preserves context propagation without rendering PHI in non-clinical pipelines.

Developer Integration

Integrate the MediGuard MCP server with your favorite AI agent environments in seconds.

Add the following block to your claude_desktop_config.json file to expose all safety tools to Claude:

{
  "mcpServers": {
    "mediguard": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/inspector",
        "node",
        "-e",
        "const http = require('http'); const req = http.request({host:'mediguard-mcp.onrender.com', path:'/mcp', method:'POST'}); // streamable transport client"
      ],
      "env": {
        "MCP_TRANSPORT": "http"
      }
    }
  }
}

To connect Cursor to the MediGuard MCP server:

  1. Open Cursor Settings (Ctrl+, or Cmd+,).
  2. Navigate to Features > MCP.
  3. Click + Add New MCP Server.
  4. Fill in the fields:
    • Name: MediGuard
    • Type: SSE (Server-Sent Events)
    • URL: https://mediguard-mcp.onrender.com/mcp

Configure these environment variables in your Render dashboard (under the "Environment" tab) for proper functionality:

Variable Name Description Default Value
MCP_TRANSPORT MCP transport protocol (stdio or http) http
PORT Port for the web server and MCP streamable transport 10000
GEMINI_API_KEY Google Gemini API key for clinical safety explanations Optional / LLM Fallback
GROQ_API_KEY Groq API key for high-speed clinical interaction synthesis Optional / LLM Fallback
DAILYMED_API_URL DailyMed REST API endpoint https://dailymed.nlm.nih.gov/dailymed
